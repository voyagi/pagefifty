How the check works

And where it stops.

  1. Code reads the numbers

    Headcounts, turnover floors and reference counts are parsed from the notice and compared with your profile by code.

  2. A model reads the language

    An NVIDIA Nemotron model on Nebius reads German, Dutch and French clauses. Every quote it returns is checked word for word against the source.

  3. Unread means ask first

    If a document pack could not be read, the page says so. A clean notice alone never shows go.
