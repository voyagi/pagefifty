# Privacy Accountability

Date: 2026-10-20

Pagefifty is a website that shows open public tenders from a dated snapshot and checks a firm's
own profile against each tender's published selection criteria in the visitor's browser. The firm
profile stays in the browser and is never sent to a server. This file records what the privacy page
(/privacy) and the AI page (/ai) state, and nothing beyond it.

## Data Subject Rights

The firm profile is never sent to a server, so it is removed where it lives: with the remove control
on the profile page, or the browser's own setting for clearing site data. A profile file the visitor
exported and keeps elsewhere is their own copy. Questions go to the repository's issue page,
https://github.com/voyagi/pagefifty/issues, as /privacy says.
